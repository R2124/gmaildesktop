Setup

This tool uses Google's official Gmail API with an OAuth "Desktop app" client that you create. Paste its Client ID and Secret below — they are encrypted with your OS keychain and stored only on this computer. Open Google Cloud Console ↗

⚠ OS-level encryption is unavailable on this machine; secrets will be stored with weak obfuscation only. Consider running on a system with a keychain/secret service.
How to create the OAuth client (one time)
  1. Go to Google Cloud Console → APIs & Services.
  2. Enable the Gmail API.
  3. Configure the OAuth consent screen (External, add your email as a test user).
  4. Create Credentials → OAuth client ID → Desktop app.
  5. Copy the Client ID and Client Secret here.
